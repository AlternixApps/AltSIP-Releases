# AltSIP Releases

This repository is reserved for AltSIP binary downloads and release notes.
Application sources and development discussions are maintained separately.

Windows beta updates are being prepared. No update feed or installation package
is published yet. Existing tester ZIP builds do not install updates automatically.

Only application packages, checksums, signed update metadata, release notes and
required third-party notices belong here. SIP accounts, passwords, recordings,
diagnostics, personal test videos and signing secrets must never be uploaded.

Бета-обновления Windows готовятся. Сборки и канал обновлений пока не опубликованы.
